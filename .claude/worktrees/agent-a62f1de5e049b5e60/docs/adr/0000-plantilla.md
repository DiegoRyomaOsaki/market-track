# ADR-NNNN — Título en una línea: la decisión, no el problema

## Contexto

Qué problema obliga a decidir, y bajo qué restricciones. Hechos, no opiniones:
presupuesto, plazo, tamaño del equipo, compromisos contractuales, límites
técnicos conocidos. Quien lea esto dentro de un año debe entender la situación
sin haber estado presente.

## Opciones consideradas

| Opción | A favor | En contra |
|---|---|---|
| **A** (la elegida) | | |
| B | | |
| C | | |

Incluir las opciones que se descartaron *y por qué*. Un ADR sin alternativas
descartadas no explica nada: la parte valiosa es el camino que no se tomó.

## Decisión

Qué se hace, en una frase afirmativa y concreta.

## Consecuencias

**Lo que ganamos.**

**Lo que aceptamos a cambio** — el costo real: lo que se vuelve más difícil, la
deuda que se contrae, lo que habrá que revisar más adelante. Si esta sección
solo tiene ventajas, el ADR está mal escrito.

**Cómo lo sabríamos si nos equivocamos** — la señal concreta que indicaría que
esta decisión fue un error, para no descubrirlo demasiado tarde.
